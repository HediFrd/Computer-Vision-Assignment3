PROJECT OVERVIEW
================================================================================
This is a complete, production-ready Structure-from-Motion (SfM) implementation
from scratch using Python, OpenCV, NumPy, and SciPy. The implementation 
reconstructs 3D scenes from video frames without using pre-built SfM libraries.
