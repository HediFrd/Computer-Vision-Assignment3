================================================================================
KEY MATHEMATICAL FORMULATIONS
================================================================================

1. FUNDAMENTAL MATRIX (8-Point Algorithm):
   - Normalized coordinates: x_norm = T @ x
   - Design matrix A: [x1*x2, y1*x2, x2, x1*y2, y1*y2, y2, x1, y1, 1]
   - SVD: A = U Σ V^T
   - F = reshape(V^T[-1])
   - Enforce rank-2: F = U @ diag([σ1, σ2, 0]) @ V^T

2. EPIPOLAR CONSTRAINT:
   - x2^T F x1 = 0 (for corresponding points)
   - Epipolar line in image 2: l2 = F x1
   - Error: |x2^T F x1| / sqrt((Fx1)_1^2 + (Fx1)_2^2)

3. ESSENTIAL MATRIX:
   - E = K^T F K (relates calibrated cameras)
   - Properties: E = U @ diag([1, 1, 0]) @ V^T
   - Decomposition: 4 possible (R, t) pairs

4. TRIANGULATION (DLT):
   - System: [pt1[1]*P1[2,:] - P1[1,:];
              P1[0,:] - pt1[0]*P1[2,:];
              pt2[1]*P2[2,:] - P2[1,:];
              P2[0,:] - pt2[0]*P2[2,:]] @ X = 0
   - Solution: X = V^T[-1] / V^T[-1][3] (from SVD)

================================================================================
COMPONENT DETAILS
================================================================================

COMPONENT 1: Video Frame Extraction
-----------------------------------
- Uses: cv2.VideoCapture, cv2.imwrite
- Input: Video file (any codec OpenCV supports)
- Output: Individual JPEG frames
- Parameters: frame_skip (default: 5)
- Key function: extract_frames_from_video()

COMPONENT 2: Feature Detection
------------------------------
- Uses: cv2.SIFT_create()
- Algorithm: SIFT (Scale-Invariant Feature Transform)
- Keypoints: ~5000 per frame (configurable)
- Descriptors: 128-dimensional vectors
- Key function: detect_and_extract_features()

COMPONENT 3: Feature Matching
-----------------------------
- Uses: cv2.FlannBasedMatcher (FLANN index)
- Algorithm: Lowe's Ratio Test
- Threshold: 0.7 (removes ~90% false positives)
- K-nearest: k=2 for ratio test
- Key function: match_features()

COMPONENT 4: Fundamental Matrix
-------------------------------
- Method 1: 8-point algorithm (normalized)
- Method 2: RANSAC for robustness
- RANSAC iterations: 2000
- Error threshold: 1.0 pixel
- Min inliers: 8 correspondences
- Key functions: compute_fundamental_matrix_8point(), compute_fundamental_matrix_ransac()

COMPONENT 5: Camera Pose
-----------------------
- Essential matrix from F and K
- Decomposition into 4 (R, t) pairs
- Validation: triangulate and count valid points
- Uses: cv2.recoverPose() or custom implementation
- Key functions: compute_essential_matrix(), recover_pose_from_essential_matrix()

COMPONENT 6: Triangulation
--------------------------
- Method: Direct Linear Transform (DLT)
- System: 4×4 homogeneous equations
- Solver: SVD (scipy.linalg.svd)
- Output: Homogeneous 4D points normalized to 3D
- Key functions: triangulate_point(), triangulate_points()

COMPONENT 7: Bundle Adjustment
------------------------------
- Objective: Minimize reprojection error
- Method: Iterative refinement (simplified)
- Optimization: Gradient descent
- Iterations: 10 (configurable)
- Key function: simple_bundle_adjustment()

COMPONENT 8: Visualization & Export
----------------------------------
- Formats: PLY (3D model format), OBJ (Wavefront)
- Visualization: matplotlib 3D scatter plot
- Color: Depth-based (Z-axis colormap)
- Output: PNG image + PLY/OBJ files
- Key functions: visualize_point_cloud_matplotlib(), save_point_cloud_ply(), export_point_cloud_obj()

================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem 1: "Not enough matches found"
Solution: Reduce frame_skip (extract more frames) or increase motion_threshold

Problem 2: "Poor reconstruction quality"
Solution: Increase RANSAC iterations or apply bundle adjustment

Problem 3: "Point cloud has outliers"
Solution: Decrease zscore_threshold or increase spatial_radius in filtering

Problem 4: "Out of memory"
Solution: Reduce image resolution or process fewer frames

Problem 5: "Degenerate scenes"
Solution: Ensure camera has translation (not just rotation) between frames
